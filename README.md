# Riverside Hospital Specialist Referral Workflow

## Project Overview

This project develops an information-system prototype for the Riverside Hospital specialist referral workflow.

The project combines:
- Strategic and operational business process modelling
- i* socio-technical modelling
- Camunda workflow automation
- User input forms
- Automated service tasks
- Testing and evaluation
- Configuration management and documentation

## Project Structure

- `models/bpmn/` – Strategic and operational BPMN models
- `models/i-star/` – Strategic Dependency and Strategic Rationale models
- `forms/` – Workflow user forms
- `service-tasks/` – Automated service-task implementations
- `testing/` – Test plans, results and evidence
- `docs/` – Supporting project documentation

## Riverside Workflow

The workflow represents the specialist referral process from receipt of a GP referral through referral assessment, appointment scheduling, specialist consultation, investigation where required, and communication of the final outcome.

## Development

The project is being developed incrementally with version control and testing applied throughout development.
